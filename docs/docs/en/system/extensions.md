# Extension Marketplace

VS Code Web integrates the [Open VSX](https://open-vsx.org) marketplace for installing extensions.

## Install

1. Click the **Extensions** icon (`Ctrl+Shift+X`)
2. Search for an extension
3. Click **Install**, then reload if prompted

> Only extensions supporting the `web` extension kind can run in the browser.

## Recommended

- **Chinese Language Pack**: `MS-CEINTL.vscode-language-pack-zh-hans`
- **Prettier**: `esbenp.prettier-vscode`
- **GitHub Theme**: themes

## FAQ

**Some extensions can't be installed?** They may not support the `web` environment — check the extension's supported environments.

**Extension not active after install?** Reload the window to activate it.
