# Theme & Chinese

VS Code Web uses the **dark theme** and **Simplified Chinese** by default, switching with the system language.

- **Chinese UI**: default Simplified Chinese; switches to English for English systems
- **Dark theme**: default; switch via command palette → **Color Theme**
- Customize via command palette → **Open Settings (JSON)**

## FAQ

**Switch back to light theme?** Command palette → **Preferences: Color Theme** → choose a Light theme.

**UI in English, want Chinese?** Command palette → **Configure Display Language** → **中文(简体)** → reload.
