# 主题与中文

VS Code Web 默认使用**暗色主题**和**简体中文**界面，并会根据系统语言自动切换。

## 中文界面

- 默认显示**简体中文**
- 如果你的浏览器/系统语言为英文，界面会自动切换为英文
- 也可手动切换：命令面板（`Ctrl+Shift+P`）→ **配置显示语言**

## 暗色主题

- 默认使用**暗色主题**，适合长时间编码
- 可在命令面板 → **颜色主题** 中切换其他主题（如 Light、High Contrast）

## 自定义

可通过 VS Code 设置自定义编辑器外观：

1. 命令面板 → **打开设置（JSON）** 或 **首选项：打开用户设置**
2. 修改如字体大小、行高、光标样式等

## 常见问题

**问：如何切换回浅色主题？**

命令面板（`Ctrl+Shift+P`）→ **首选项：颜色主题** → 选择 Light 主题。

**问：界面变成英文了，怎么改回中文？**

命令面板（`Ctrl+Shift+P`）→ **配置显示语言** → 选择 **中文(简体)** → 重新加载。
