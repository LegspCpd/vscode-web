# GitHub 远程集成

VS Code Web 原生集成了 **GitHub 远程仓库**的浏览与编辑，无需在浏览器中安装 Git，即可像操作本地项目一样操作远程仓库。

## 登录 GitHub

1. 打开站点后，点击左侧活动栏的 **GitHub** 图标
2. 点击 **登录** 按钮
3. 在弹出的居中授权窗口中完成 GitHub 授权
4. 授权成功后弹窗自动关闭，页面自动刷新，侧边栏即显示你的仓库列表

## 浏览仓库

登录后，侧边栏会展示你的所有仓库：

- 点击仓库可展开查看文件树与分支
- 点击任意文件会在**主编辑器**中打开，并进行**语法高亮**与**代码补全**

## 编辑并保存

1. 在主编辑器中直接修改文件内容
2. 点击侧边栏顶部的 **保存当前** 按钮（或刷新按钮旁的保存图标）
3. 改动会通过 GitHub API 写回对应仓库

> 编辑器顶部还提供 **保存** 命令（`GitHub: 保存文件`），可在命令面板（`Ctrl+Shift+P`）中调用。

## 切换语言

打开文件后，可在右下角状态栏或命令面板（`Ctrl+K M`）中**切换语言模式**，以启用对应语言的语法高亮与补全。内置支持：

JavaScript、TypeScript、JSON、HTML、CSS、Python、Markdown、YAML、C++、Go、Rust、PHP、Shell、Java、C#、XML、SQL

## 已登录与未登录

- **未登录**：仍可使用 VS Code 的本地编辑功能（新建文件、语法高亮、补全等）
- **已登录**：额外获得远程仓库浏览、打开、编辑、保存能力

## 常见问题

**问：如何退出登录？**

在 GitHub 侧边栏中点击退出/注销按钮即可。退出后远程仓库功能不可用，本地编辑功能不受影响。

**问：编辑的是真实仓库还是副本？**

编辑的是你 GitHub 账号下的**真实仓库**。点击保存后即写回远程仓库，请注意操作。

**问：可以同时打开多个文件吗？**

可以。VS Code Web 支持多标签页、多编辑器组布局，与桌面版一致。
