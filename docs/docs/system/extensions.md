# 扩展市场

VS Code Web 集成了 [Open VSX](https://open-vsx.org) 扩展市场，可在线安装和使用 VS Code 扩展。

## 打开扩展视图

点击左侧活动栏的 **扩展** 图标（或按 `Ctrl+Shift+X`）。

## 安装扩展

1. 在扩展搜索框中输入扩展名称（如 `Chinese`、`Prettier` 等）
2. 在搜索结果中点击目标扩展
3. 点击 **安装** 按钮
4. 安装完成后按提示 **重新加载** 或直接使用

> 由于浏览器沙箱限制，并非所有扩展都能在 Web 中运行。只有声明支持 `web` 或 `universal` 扩展类型的扩展才能安装使用。

## 推荐扩展

- **中文语言包**：`MS-CEINTL.vscode-language-pack-zh-hans`（界面中文化）
- **Prettier**：`esbenp.prettier-vscode`（代码格式化）
- **GitHub Theme**：主题美化
- **Live Server**：本地预览

## 说明

- 扩展市场地址为 Open VSX（由于版权原因，VS Code 官方扩展市场无法在 Web 中使用）
- 通过扩展市场安装的扩展会保存在浏览器本地存储中，刷新后保留

## 常见问题

**问：为什么有些扩展无法安装？**

如果扩展不支持 `web` 扩展类型，则无法在浏览器中运行。可查看扩展详情页是否标注支持 Web。

**问：安装后扩展不生效？**

安装后可能需要重新加载窗口才能激活扩展。可按提示点击 **重新加载**。
